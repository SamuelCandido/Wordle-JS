## 🎯 Objetivo

Recriar a experiência do jogo Wordle, onde o jogador tenta adivinhar uma palavra secreta em até 6 tentativas. As letras são marcadas com cores para indicar acertos na posição ou presença fora de posição.

---

## 🚀 Como Executar

### ✔️ Versão Web

1. Clone o repositório:

```bash
git clone https://github.com/SamuelCandido/Wordle-JS.git
cd Wordle-JS
```

2. Abra o arquivo `index.html` no navegador.

### 🐍 Versão Python

```bash
cd Executavel
python wordle.py
```
